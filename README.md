# ePod: A Portable E-Paper High-Fidelity Wireless Audio Player

Coming soon!!

Features:
- ESP32-S3 with 2MB PSRAM and 4MB flash
- Reverse-engineered iPod 5th Gen clickwheel
- 3000mAh rechargeable battery with fuel gauge (BQ25185 and MAX17048)
- USB-C DAC/AMP mode: connect the device to a PC to use as a high-fidelity audio DAC/AMP!
- CS43131 DAC/AMP for nice and crispy audio (or whatever audiophiles call it)
- Bluetooth 5.3 audio playback (supports standard Bluetooth wireless headphones)
- MicroSD Card support to store songs
- Setup, configuration, and file transfer over Wi-Fi

All in a portable 53mm (W) x 118mm (H) x 18mm (T) package!
